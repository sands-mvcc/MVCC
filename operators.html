01

Arithmetic operators

Seven operators do all of Python's math. Five behave the way you expect from a calculator. Two, floor division and modulo, are the ones programmers use constantly and beginners rarely know.

You will be able to

  • Use all seven arithmetic operators and predict whether the result is an int or a float
  • Explain the difference between / and //, and use % to find a remainder
  • Update a variable with augmented assignment such as +=

Result types: two ints give an int, except with /, which always gives a float. If either side is a float, the result is a float: 2 * 3.0 is 6.0.

Where % shows up in real programs

n % 2 == 0 tests for even numbers. i % 10 == 0 does something every tenth pass of a loop. (hour + 5) % 24 wraps a clock past midnight. year % 4 is the first test for a leap year, and seconds % 60 gives the seconds left after removing whole minutes.

Augmented assignment: += and friends

count += 1 is shorthand for count = count + 1. Every arithmetic operator has a version: -=, *=, /=, //=, %=, **=. The variable must already exist, or you get a NameError.

Why 0.1 + 0.2 is not exactly 0.3

Floats are stored in binary, and most decimal fractions cannot be stored exactly, just as 1/3 cannot be written exactly in decimal. 0.1 + 0.2 gives 0.30000000000000004. Never test floats with ==; round them first with round(x, 2), or check that the difference is tiny. For money, count whole cents with ints.

02

Order of operations

When an expression mixes operators, Python decides which to do first by precedence. When two operators have the same precedence, associativity breaks the tie. Parentheses override both.

You will be able to

  • Evaluate a mixed expression step by step in the order Python uses
  • Add parentheses to change the result or to make intent clear
  • Translate a formula from math notation into correct Python

Precedence, highest first

( )Parentheses: always evaluated first
**Exponent, grouped right to left: 2 ** 3 ** 2 is 2 ** 9
-xNegation: -2 ** 2 is -4, because ** binds tighter
* / // %Multiplication and division family, left to right
+ -Addition and subtraction, left to right

notLogical negation

orLowest of all: at least one must be true

Classic bug: average = a + b / 2 divides only b. The formula you meant is (a + b) / 2. When in doubt, add parentheses; they cost nothing and make your intent obvious to the next reader.

04

Logical operators

and, or, and not combine True/False answers into one decision. They are how a program expresses rules like “admins or owners, who passed MFA, on an unlocked account.”

You will be able to

  • Build and read truth tables for and, or, and not
  • Explain short-circuit evaluation and use it to guard risky operations
  • Apply De Morgan's laws and parenthesize mixed and/or rules correctly

Logic gatesFlip A and B. The lamps show each operator's result, and the matching row of the truth table lights up.

Short-circuit evaluation

Python stops as soon as the answer is certain. In a and b, if a is False, the result must be False, so b is never evaluated. In a or b, if a is True, b is skipped. This lets you write guards such as count != 0 and total / count > 50, which never divides by zero.

De Morgan's laws

not (a and b) is the same as not a or not b, and not (a or b) is the same as not a and not b. To negate a combined rule, flip each part and swap and with or. For example, “not between 13 and 19” is age < 13 or age > 19.
