    Where the paint analogy breaks

    Paint is a great picture of the idea, but it isn't a perfect model. A chemist with a spectrometer could probably work out which pigments went into a mix, so "un-mixing" is hard rather than impossible. Real Diffie-Hellman replaces paint with modular exponentiation, where reversing the step (the discrete logarithm problem) has no known fast method for well-chosen numbers on classical computers.

    Paint also hides how much secret is in play. There are only a few thousand paint colors anyone could tell apart, while a 2048-bit Diffie-Hellman secret has a number of possibilities with more than 600 digits. The Play as Eve and Brute-force race tabs make that difference concrete.

      How real protocols seal the pot

      In TLS 1.3 the server signs the handshake, including its key share, with the private key behind its certificate. Your browser checks that signature against a certificate chain it trusts. Mallory can still swap key shares, but she can't produce a valid signature for someone else's domain, so the connection fails instead of quietly leaking. SSH does the same job with host keys, which is why SSH warns you when a server's host key changes.

      From paint to math

      The public paint becomes a number g, and mixing in a secret a becomes ga mod p. "Mod p" means you keep only the remainder after dividing by p, so every answer lands somewhere on a clock with p − 1 positions.

      Modular clock

      Watch the powers of g hop around the clock. A good generator visits every position, so every secret gives a different public value.

      Real world and quiz

      You've almost certainly used Diffie-Hellman today. Modern systems mostly use the elliptic-curve version (ECDH), which gives the same security with much smaller numbers.

      • HTTPS (TLS 1.3)Every connection runs a fresh ephemeral exchange, usually X25519. Browsers now also mix in ML-KEM, a post-quantum algorithm standardized by NIST in 2024, as a hybrid.
      • SSHThe key exchange that runs before you even type a password. Host keys play the seal role from the Mallory tab.
      • VPNsIPsec's IKE and WireGuard both run Diffie-Hellman to set up tunnel keys.
      • Secure messagingSignal, and WhatsApp's use of the Signal protocol, run chains of ECDH exchanges so each message gets fresh keys.
      See it yourself in Wireshark

      Start a capture, visit any HTTPS site, and filter with tls.handshake.type == 1 to find the Client Hello. Expand Extension: key_share and you'll see the group your browser offered and its public value, the number Eve gets to see. The Server Hello carries the server's half. Nothing in the capture reveals the shared secret.

      Strengths, limits, and what to use

      Forward secrecy comes from ephemeral exchanges (DHE, ECDHE), with new secrets every session, so stealing a server's long-term key later doesn't unlock old recordings. Authentication isn't built in; pair the exchange with signatures and certificates or Mallory wins. Parameters matter: the 2015 Logjam attack forced connections down to 512-bit "export" groups and showed that widely shared 1024-bit primes were within reach of precomputation. Use standard groups (RFC 7919 for finite-field DH) of at least 2048 bits, or prefer X25519. Quantum computers running Shor's algorithm would break both DH and ECDH, which is why hybrid post-quantum key exchange is already rolling out.
