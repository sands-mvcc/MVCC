Arrays: numbered slots in one block of memory

An array stores items side by side in a single, contiguous block of memory. Each slot has an index, starting at 0. Because every slot is the same size, the computer never searches for an item: it calculates where the item is.

That calculation is the whole secret of the array. For an array of 4-byte integers starting at address 0x1000, element 3 lives at 0x1000 + 3 × 4 = 0x100C. One multiplication and one addition, no matter whether the array holds 8 items or 8 million. That is O(1) access.

The price is paid when the shape changes. Inserting at the front means every existing item must move one slot to the right, and deleting from the front means they all move left. That is O(n) work.

Stacks: the last one in is the first one out

A stack only lets you touch one end, called the top. Push places an item on top, pop removes the top item, and peek looks at it without removing it. Think of a stack of plates: you never pull one from the middle.

Built on an array, a stack needs a single integer, top, that records the index of the newest item. Push increments it and writes; pop reads and decrements. Neither operation moves any other element, so both are O(1).

Your own programs run on a stack. Every function call pushes a frame holding its local variables and the address to return to; every return pops it. Recursion that never stops keeps pushing until the call stack overflows.

Security connection. If a program copies more bytes into a local buffer than the buffer holds, the extra bytes spill over neighbouring stack data, including the saved return address. An attacker who controls those bytes can redirect execution. Bounds checks like the ones in the lab below are the first defence.

Bracket checker: a stack solving a real problem

Compilers and HTML validators use a stack to confirm that every opener has a matching closer in the right order. Openers are pushed; each closer must match the item on top, which is then popped. The string is balanced only if the stack is empty at the end.

See it in code: an array-backed stack 
class Stack:
    def __init__(self, capacity):
        self.items = [None] * capacity
        self.top = -1                    # -1 means empty

    def push(self, value):
        if self.top == len(self.items) - 1:
            raise OverflowError("stack overflow")
        self.top += 1
        self.items[self.top] = value

    def pop(self):
        if self.top == -1:
            raise IndexError("stack underflow")
        value = self.items[self.top]
        self.top -= 1
        return value
public class IntStack {
    private final int[] items;
    private int top = -1;                // -1 means empty

    public IntStack(int capacity) { items = new int[capacity]; }

    public void push(int value) {
        if (top == items.length - 1) throw new IllegalStateException("overflow");
        items[++top] = value;
    }

    public int pop() {
        if (top == -1) throw new IllegalStateException("underflow");
        return items[top--];
    }
}

Queues: the first one in is the first one out

A queue is a waiting line. Enqueue adds an item at the rear; dequeue removes the item at the front. Whoever has waited longest is served next, which is exactly what printers, network routers and operating-system schedulers need.

A naive array queue that always removes from index 0 must shift every remaining item left, an O(n) cost on every dequeue. The fix is the circular buffer: leave items where they are and move two pointers instead. When a pointer runs off the end of the array it wraps back to 0 using the remainder operator.

rear = (rear + 1) % capacity

With wrapping, both enqueue and dequeue are O(1), and the array's space is reused forever.

See it in code: a circular queue 
class CircularQueue:
    def __init__(self, capacity):
        self.buf = [None] * capacity
        self.front = self.rear = self.count = 0

    def enqueue(self, value):
        if self.count == len(self.buf):
            raise OverflowError("queue full")
        self.buf[self.rear] = value
        self.rear = (self.rear + 1) % len(self.buf)    # wrap
        self.count += 1

    def dequeue(self):
        if self.count == 0:
            raise IndexError("queue empty")
        value = self.buf[self.front]
        self.front = (self.front + 1) % len(self.buf)  # wrap
        self.count -= 1
        return value
public class IntQueue {
    private final int[] buf;
    private int front = 0, rear = 0, count = 0;

    public IntQueue(int capacity) { buf = new int[capacity]; }

    public void enqueue(int value) {
        if (count == buf.length) throw new IllegalStateException("full");
        buf[rear] = value;
        rear = (rear + 1) % buf.length;      // wrap
        count++;
    }

    public int dequeue() {
        if (count == 0) throw new IllegalStateException("empty");
        int value = buf[front];
        front = (front + 1) % buf.length;    // wrap
        count--;
        return value;
    }
}
