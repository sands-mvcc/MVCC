        Your goal

        Run M-101 to 60 Hz and stop it back to 0 Hz in one clean cycle with no trip. When it trips, read the fault code and the drive manual excerpt below, change one parameter, reset, and try again.

        Fault history

        • No faults recorded this shift.
        Drive manual: fault codes

        OC1, overcurrent during acceleration. Output current exceeded 150% of motor FLA while ramping up. Causes: acceleration time too short for the load inertia, mechanical binding, shorted motor lead.

        OV2, DC bus overvoltage during deceleration. The load drove the motor as a generator faster than the drive could dissipate the energy. Fixes: longer deceleration time, a dynamic braking resistor, or coast-to-stop where the process allows it.

            Work order study guide

            Study each work order before you open it: know the requirement, the procedure, and the result that proves you’re done. The same guide appears at the top of every work order, so you can check it mid-task.

            How to use this guide

            Every work order follows the cycle a field technician uses: prepare, perform, verify, document. Read the guide for a work order, answer its self-check questions without looking back, then start the task. Faults are randomized, so memorizing an answer won’t work; learn the signatures. Wrong answers come with an explanation, so treat a miss as part of the lesson.

            Each guide has the same parts: the requirement to close, key concepts, the procedure, the results to look for, common mistakes, and a self-check.
