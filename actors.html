    Excessive failed logons

    Raises an alert when one source IP produces too many failed logons (Event ID 4625) inside any 10-minute window.

    EventCode=4625 | bin _time span=10m | stats count AS failures, dc(user) AS accounts BY src_ip, _time | where failures >= 50

    Lower values catch more attacks but raise more false positives. Higher values are quieter but can miss attacks.
