01

Variables

A variable is a name that points to a value stored in memory. You create one with a single =, and you can change it whenever you like.

You will be able to

  • Create variables that hold whole numbers, decimals, text, and true/false values
  • Predict a variable's value after it has been reassigned
  • Read a TypeError and fix it by converting between types

Read age = 36 as “store 36 under the name age,” not “age equals 36.” Python always evaluates the right side first, then attaches the result to the name on the left. That is why age = age + 1 makes sense: take the current age, add one, store the result back under the same name.

Naming rules and conventions

Names may contain letters, digits, and underscores, but cannot start with a digit. They are case-sensitive, so Score and score are different variables. Keywords such as if, for, and def are reserved.

Python programmers write names in snake_case and choose names that describe the value: failed_logins tells the next reader far more than x.

02

Conditions

A condition lets a program choose. Python tests a true-or-false question and runs a block of code only when the answer is True.

You will be able to

  • Write boolean expressions with comparison operators and and, or, not
  • Trace which branch of an if / elif / else chain runs
  • Test the boundary values where a program's behavior changes

Python checks the conditions from top to bottom and runs only the first branch whose test is True. Everything after that is skipped. else catches whatever is left. The indented lines under each test are its block.

03

Loops

A loop repeats a block of code. Use for when you know what to step through, and while when you repeat until something changes.

You will be able to

  • Choose between a for loop and a while loop
  • State exactly which values range() produces
  • Build a running total with the accumulator pattern
  • Diagnose and fix an infinite loop

04

Functions

A function is a named, reusable block of code. You define it once with def, then call it as many times as you need, handing it different inputs each time.

You will be able to

  • Define functions with parameters and a return value
  • Explain the difference between print and return
  • Break a task into functions and check them with test calls

Defining a function does not run it. The body runs only when you call the function by writing its name with parentheses. The names in the def line are parameters; the values you pass in a call are arguments. return hands a value back to the caller, which can store it, print it, or pass it to another function.

Function machinePick a function, give it an argument, and call it. Then try shout, which prints instead of returning. Compare what appears on screen with what the call hands back.
