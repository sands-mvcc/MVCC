    Station 1

    Classical ciphers

    The Caesar cipher shifts every letter by a fixed amount. The shift is the key. Use the wheel to encrypt and decrypt, then attack ciphertext two ways: by trying every key, and by counting letters.

    Cipher machine

    Outer ring is plaintext; inner ring is ciphertext. The wheel’s shift is applied to whatever you type.

    Task 1.3: Frequency analysis

    5 pts

    Substitution ciphers keep the language’s letter frequencies. Find the tallest bar, assume it stands for the most common English letter, and work out the key.

    Hint

    In English, E is usually the most frequent letter. Count how many positions forward from E the tallest letter sits. That distance is the encryption shift.

    Takeaway: a cipher with 25 keys falls to brute force in seconds, and any monoalphabetic substitution leaks letter patterns. Modern ciphers defeat both attacks with enormous keyspaces and output that looks random.

    Task 2.4: The key distribution problem

    3 pts

    A 12-person incident response team needs a private channel between every pair of members, using only symmetric keys. How many unique keys must be created and securely distributed?

    Takeaway: symmetric ciphers are fast enough for bulk data, and authenticated modes like GCM detect tampering. The hard part is getting the same secret key to everyone safely. That’s the problem asymmetric cryptography solves.

    Station 3

    Asymmetric encryption with RSA

    Each person has a key pair. The public key is shared with anyone; the private key never leaves its owner. First build a tiny RSA key by hand so the math is visible, then generate a real one.

    Task 3.1: RSA by hand

    12 pts across 5 steps

    Step 1: Pick two primes and compute n

    n = p × q

    Step 2: Compute Euler’s totient φ(n)

    φ(n) = (p − 1) × (q − 1)

    Step 3: Choose the public exponent e

    1 < e < φ(n), and gcd(e, φ(n)) = 1. Small primes like 3, 5, 7, 11, or 17 are good tries.

    Step 4: Compute the private exponent d

    (e × d) mod φ(n) = 1, the modular inverse of e

    Step 5: Encrypt and decrypt a number

    Public key (e, n)
    Private key (d, n)

    c = me mod n    then    m = cd mod n
