    Work faster with any AI assistant

    Most of the time saved with an LLM doesn’t come from the model. It comes from how you drive it: the keys you press, the commands you type, and the instructions you package once and reuse forever.

    Three layers of efficiency

    Each layer saves more time than the one before it, because it captures more of your intent in fewer actions.

    Layer 1Shortcuts Keys that drive the interface: new chat, copy, focus, accept a suggestion. Saves seconds, dozens of times a day. Layer 2Commands Slash commands, @ mentions and prefixes that control the session itself: compact context, pull in a file, switch the model. Layer 3Skills and reuse Packaged expertise: Skills, Projects, Gems, GPTs and instruction files. Write it once, and every future task starts ahead.

    Command console

    Chat apps mostly use menus and @ mentions. Agentic tools in the terminal and editor use real slash commands. Pick a tool, then type /, @, ! or # in the simulator to explore what each command does and why it saves time.

      Full reference

      Simulator only: nothing is sent anywhere. Command names change between releases, so check /help in your installed version. Custom commands are also possible: Claude Code reads Markdown files in .claude/commands/, Gemini CLI reads files in .gemini/commands/, and VS Code Copilot supports reusable prompt files.

      Skills and reuse

      A Skill is a folder of instructions, plus optional scripts and reference files, that an assistant loads only when the task calls for it. It’s how you turn your best prompt into a reusable capability instead of retyping it.
