Every machine makes the same trade.

A simple machine lets you push with less force by pushing over a longer distance, or move something farther by pushing harder. It can also change the direction of a push. What it can’t do is give back more work than you put in.

About the models

Each lab uses the standard ideal model from introductory physics, then adds friction so the measured effort is larger than the ideal effort. For most machines, friction appears as a percentage of input work lost. The inclined plane uses a coefficient of friction instead, because that’s how ramp friction is usually measured. The wedge uses the simple geometric model: ideal mechanical advantage equals taper length divided by thickness.

Forces are in newtons (N), distances in meters (m), and work in joules (J). Your recorded trials are saved in this browser only.

Principles that apply to all six

These five ideas connect what you see a machine do with the calculations that explain how well it does it.

Input and output

Every machine has an input, where you apply the effort, and an output, where the machine acts on the load. To analyze any machine, find both points, the direction of each force, and how far each point moves.

In a sketch, draw the effort arrow at the input, the load arrow at the output, and note the distance each one travels.

Work

For a constant force parallel to the motion, work is force times distance.

W = F × d    (N × m = J)

Applying a force isn’t the same as doing work. If you push on a box that doesn’t move, the displacement is zero, so the work done on the box is zero.

Mechanical advantage
Ideal (IMA) = input distance ÷ output distance, or from geometry
Actual (AMA) = output force ÷ input force

Above 1, the machine multiplies force. Exactly 1, the forces are equal (it may still change direction). Below 1, the machine trades force for greater output distance or speed, as tweezers do.

Efficiency
Efficiency = output work ÷ input work × 100% = AMA ÷ IMA × 100%

A machine can multiply force and still be well under 100% efficient. A screw jack lets one hand lift a car, yet most of the input work turns into heat at the threads.
